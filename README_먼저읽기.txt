체인지클린 MOMO V7 전체생성기

[확정 반영]
1. '시공 현장' -> '청소 현장'
2. V6 디자인/구조 유지
3. 실시간 견적문의 3줄 노출 + 자동 롤링 유지
4. 청소 현장: 현재 지역 + 인근 지역 + 아파트/빌라/오피스텔 등 로테이션
5. 우측 고정: 전화상담 + 간편견적
6. Formspree mvzlylrr 유지
7. 업로드 이미지 풀 299장 유지
8. 지역당 롱테일 검색의도 10개
9. 페이지별 이미지 조합 자동 변경
10. 전체 생성된 페이지끼리 내부링크 URL 생성

[실행]
RUN_전체생성.bat 더블클릭
또는
python generate_all.py

[중요]
regions.csv가 전체 지역 목록입니다.
현재 패키지에는 구조 검증용 지역 목록이 들어 있습니다.
여기에 서울/경기/인천 전체 동 목록을 추가하면
동 개수 x 10개의 페이지가 생성됩니다.

generated_site 폴더가 Netlify/GitHub 배포 대상입니다.
